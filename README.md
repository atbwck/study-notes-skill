# study-notes

一个 agent skill：把一份技术资料（官方文档、博客、PDF/EPUB 电子书、视频）整理成一份 Markdown 学习笔记。

产出的笔记每节都写清**作者教什么、为什么、怎么做**，条目按学习顺序重排（不照资料原有章节），原文重要短句就近引用，重要插图就近收录。

## 安装

目录名要与 `SKILL.md` 里的 `name` 一致：

```bash
git clone https://github.com/<you>/study-notes-skill.git ~/.agents/skills/study-notes
```

也可放进项目的 `.agents/skills/study-notes/`，只在那个仓库生效。

## 用法

直接说你要做什么，模型会自己触发：

```
把 https://example.com/some-blog 整理成笔记
把 ~/Downloads/某本书.pdf 做成学习笔记
这篇文档梳理一下，我要能照着做
```

也可以强制调用：`/skill:study-notes <你的要求>`

## 产出长什么样

```markdown
# 资料名

- 作者：
- 版本 / 时长：
- URL：
- 笔记更新：2026-10-20

## 概括
（3–5 句：讲什么、核心主张、覆盖到哪）

## 正文

### 1 标题

**教什么**：这节要让读者学会什么

> 原文重要短句

**为什么**：作者给出的理由或机制

**怎么做**：资料明确给的做法、步骤、条件、限制

![图说明什么](assets/主题/01-xxx.png)

### 未说明 / 未覆盖
资料没说的、无法核验的
```

## 它自带什么

- **环境探测**：开场先查 PDF 提取、OCR、字幕等能力，缺什么**先问你**再装，不擅自动手
- **取文本**：四类资料的处理方式，含扫描版 PDF 的完整 OCR 调用代码
- **写笔记规则**：三问结构、引用规则、图与动图规范、边界
- **交付前自检**：8 项检查，其中引用回查、三问检查、日期回填都附可直接运行的脚本

不依赖任何外部脚本或子技能，单个 `SKILL.md` 即完整可用。

## 已知边界

- 视频路径需要 `yt-dlp`（取字幕）与 `ffmpeg`；无字幕时才需要 `faster-whisper`（模型数百 MB）
- 注释里的规则来自实测：扫描版 PDF 与技术博客各跑过一轮，视频路径尚未实测
