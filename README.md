# study-notes

将文档、文章、PDF、EPUB、视频或指定主题整理成可追溯、可复习的 Markdown 学习笔记，支持英文资料生成中文笔记，也可以对照原资料检查并重构已有笔记。

## 功能

- **知识覆盖**：从原资料建立章节与知识点清单，记录每个要点在笔记中的去向，检查定义、条件、例外、推导、参数、图表和脚注。
- **结构组织**：按知识依赖和学习目标展开。概念保留定义与辨析，原理保留前提与推导，操作保留步骤与验证，论证区分主张与证据。
- **中文输出**：默认使用用户语言，可将英文原文整理为中文笔记；可以指定术语中英对照、重要引文附译文。
- **学习与复习**：提供闭卷回忆、辨析、自我解释和应用题，答案单独放置，支持先作答、再核对纠错与跨次复习。
- **来源追溯**：重点结论就近标注章节、页码、时间戳或链接，区分原文、整理归纳与外部补充，明确未读范围和待核实内容。

研究依据与适用限制见 [学习科学说明](references/learning-science.md)。结构与练习会根据资料、目标和已有基础调整。

## 安装

安装到 agent 实际读取的技能目录，目录名保持为 `study-notes`。例如，安装到共享用户目录：

```bash
git clone https://github.com/atbwck/study-notes-skill.git ~/.agents/skills/study-notes
```

项目级安装可放在 `.agents/skills/study-notes/`；其他 agent 使用其支持的技能目录。

保留完整的 `SKILL.md`、`references/`、`scripts/` 和 `agents/`。安装后在宿主技能列表或新会话中确认已发现 `study-notes`。

## 用法

直接说明资料、学习目标和输出位置：

```text
请使用 study-notes，把这份 PDF 整理成完整学习笔记，
保留推导和适用条件，附闭卷自测，保存到我的笔记目录。
```

Codex 可明确提及 `$study-notes`；其他宿主的调用语法以实际支持为准。

```text
$study-notes 帮我学习这个主题，先明确前置知识，再用权威资料组织笔记。
$study-notes 对照原文检查这份笔记是否遗漏了例外、图表或参数，并重构目录。
$study-notes 仅整理第 2 章，控制在 500 字以内，不需要练习。
```

### 英文资料生成中文笔记

读取英文原文后，用中文组织知识与解释。可以明确要求双语术语和引文翻译：

```text
$study-notes 将这份英文电子书整理成中文学习笔记。
首次出现的关键术语使用“中文（English）”格式，
代码、API 名称、命令和公式保持原样。
重要英文引句附中文译文，保留章节或页码定位。
完整保留前提、例外和推导，并提供题目与答案分开的闭卷自测。
```

默认产出是整理后的学习笔记；需要逐句对照翻译时，在请求中单独说明。

## 产出

完整学习笔记通常包含：

1. 来源、版本、笔记更新日期、学习范围与必要前置。
2. 整体问题、主要概念及其关系。
3. 按知识依赖展开的正文，来源就近标注，相关图表就近放置。
4. 闭卷自测，以及分开放置的答案、判分要点与正文定位。
5. 实际存在的未覆盖项、待核实内容和范围边界。

长书或课程可拆成索引与章节笔记。输出遵循笔记库已有格式；用户指定仅归档、篇幅或版式时按要求调整。

长资料、多来源或查漏任务另存覆盖记录到 `.study-notes-audit/`，便于检查与续写，工具日志和覆盖清点不混入知识正文。

## 能力边界

- 使用当前环境的读取、浏览、OCR 和转写能力，不内置这些引擎；缺失能力时说明并选择替代。
- 英文与中文资料都需要能够读取正文。OCR、自动字幕中的关键数字、公式和引文仍需核对原件。
- 笔记完整性针对约定范围与实际读取资料。访问受限或内容缺失时交付部分成果，并列出待补项。
- 闭卷练习与复习需要学习者实际参与；不承诺某种版式、固定复习日程或自动生成笔记必然带来长期记忆。
- 格式与脚本测试不等同于跨格式全流程或学习效果验证。已执行检查及其范围见 [验证记录](evals/validation-2026-10-23.md)。
