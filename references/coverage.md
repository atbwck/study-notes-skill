# 覆盖记录与遗漏核验

## 两级清单

资料单元来自资料本身的目录与实际正文；无目录时按正文主题或连续时间段划分。先建立清单，再逐单元补充知识点。核对实际页数、章节和视频时长，防止目录本身漏掉附录或正文抽取中断。

对每个实质知识点记录：含限定条件的完整表述、精确来源位置、正文去向和处理状态。不要把“出现了同名词语”“有一段讨论这个主题”作为已覆盖。

提取时根据内容检查相关维度，不要求每份资料都有所有维度：

| 内容 | 易漏的信息 |
| --- | --- |
| 定义与分类 | 上下位关系、必要/充分条件、互斥或重叠、相邻概念区别 |
| 主张与机制 | 因果方向、前提、中间推导、证据、相反观点与不确定性 |
| 定量内容 | 符号、单位、取值范围、公式假设、比较基准与数值例子 |
| 操作与 API | 环境/版本、输入、顺序、默认值、边界值、错误分支和输出验证 |
| 图表与附注 | 坐标/图例、趋势成立区间、脚注限制、正文省略的关键关系 |
| 实例 | 能否揭示机制、边界、误解或操作过程；这些信息应并入对应知识点 |

合并重复知识时保留全部不同条件和来源。同一词在两份资料中的定义不同，应并列辨析。省略广告、非知识性修辞、纯重复或用户明确范围外内容时记录理由；核心例外与证据不能当作背景删除。

## 机械记录格式

大任务的记录是持久工作材料，不是额外的知识章节。以下是一个可运行的小例子：相对于记录文件所在目录，`../主题.md` 中应存在唯一的 `## 重试边界`。

```json
{
  "scope": "S1 第 2 节：重试的适用条件",
  "sources": [
    {
      "id": "S1",
      "location": "https://example.org/manual#retry",
      "access": "complete"
    }
  ],
  "units": [
    {
      "id": "U1",
      "source": "S1",
      "locator": "第 2 节",
      "status": "read"
    }
  ],
  "items": [
    {
      "id": "K1",
      "unit": "U1",
      "locator": "第 2 节，第 3 段",
      "point": "仅在请求幂等或带去重标识时自动重试。",
      "status": "covered",
      "target": {"file": "../主题.md", "heading": "重试边界"}
    }
  ]
}
```

- `sources.access`：`complete`、`partial`、`unavailable`。范围是所声明的来源范围，不代表链接所在整个网站。后两者需要 `reason`。
- `units.status`：`read`、`excluded`、`unavailable`。范围外或非知识单元使用 `excluded`，同时提供 `basis` 与 `reason`。读取到的实质单元至少有一个知识点；空单元先确认是否抽取失败。
- `items.status`：`covered`、`merged`、`omitted`、`gap`。前两者需要 `target`；后两者需要 `reason`。
- `basis` 允许 `out_of_scope`、`nonknowledge`、`duplicate`。重复省略的项仍须指向保留内容；资料单元不能整章只因“重复”就跳过，先逐点核实。
- `target.file` 相对于记录文件，`target.heading` 是目标 Markdown 中完整且唯一的标题文本，不含 `#` 前缀。使用 ATX 标题（`## 标题`）。

运行：

```text
python <skill-dir>/scripts/check_coverage.py <audit.json>
```

退出码：`0` 表示记录结构与目标有效且没有已登记缺口；`1` 表示记录或目标有错误；`2` 表示存在部分来源、不可读单元或待补点。脚本只读文件，使用 Python 标准库。

**范围限制**：记录由整理者填写，脚本不能识别漏建的章节、漏列的知识点、虚假的“已读”或正文实际误述，也不验证互联网来源。不要把其计数称作事实完整率或学习掌握率。

## 反向检查与停止条件

1. **原资料 → 笔记**：脱离成稿结构，逐单元核对含义、条件、证据、例外、图表与脚注。长文检查首、中、尾提取是否连续；完整笔记仍须处理所有范围内单元。
2. **笔记 → 原资料**：每个核心结论能定位到支持它的段落、页码、时间段或图表。改写检查含义，引文检查实际措辞，二者不能混用判据。
3. **问题 → 答案 → 正文**：自测答案能从正文推出，应用题没有偷带新事实；认知目标与题型相符。

可读取的范围内没有未处理单元或待补点时，才称“已完成约定范围”。有访问障碍时保留缺口，交付部分成果；不能反复重试同一失败操作或把模型常识填入缺口来消除告警。
