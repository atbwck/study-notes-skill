# 资料读取、定位与引用

按资料类型只读需要的分支。优先使用会话已有工具。缺少能力时选择现有替代；确实需要额外安装、付费转写或大模型下载时，遵循当前授权并说明需要什么，避免每次任务先跑整套环境清单。

## 网页与文档站

读取正文、表格、代码块、图注、脚注及与指定范围相关的子页面。搜索结果摘要、目录和导航页不是全文。官方文档记录版本；跨页内容先列出范围内页面再逐页处理。

文字提到“上图”“动画”而提取结果缺少对应媒体时，用可用浏览器或原 HTML 检查正文区域，处理懒加载、`srcset` 与相对资源路径。不要把侧栏推荐图当正文插图。

页面有登录、付费或访问限制时保留可见范围，不把未读部分称为已读。引用网页时尽可能定位到小节或段落；长文重排后不能只留开头一个总 URL。

## PDF 与扫描资料

先检验实际文本质量和总页数。文字层正常则提取并保留页码；混合 PDF 按页选择文本提取、视觉读取或 OCR，不要求所有页面一律 OCR。

OCR/文字层可能错列、多栏串行、丢表格、负号、上下标和公式。关键数值、公式、表格关系和直接引文要对照原始页面；仅在同一 OCR 文本中检索成功不能证明准确。

记录 PDF 文件页码与印刷页码的区别。句子仅因分页断开时，检查原始相邻页确认阅读顺序与语义连续，引用注明页码范围；无法核实时改为可追溯的转述或标注不确定，不能任意拼接不连续文本。

## EPUB

依据阅读顺序读取 XHTML，保留章节锚点。检查正文之外的图注、表格与相关脚注，避免按 ZIP 内的文件名排序。动态字体、数学表示或图形无法读取时说明局限。

## 视频与音频

优先作者字幕，其次自动字幕或可用转写。记录内容时间范围和字幕类型，核对技术术语、数字、公式和口误。时间戳是定位，不是准确性的保证。

截图能补充画面，不能替代未获得的口述。无字幕且无法转写时，只能交付明确标为“画面观察”的部分笔记。关键演示记录前置、操作、状态变化和结果；不要只收录菜单截图。

## 图片、动图与代码

使用对理解有增量的原图，存到笔记约定的资产目录，默认 `assets/<笔记名>/`，以相对路径引用并写来源定位。图注说明可见内容与知识关系。确有帮助的整理者关系图可新建，但标明是根据正文整理，不能伪装成原图。

动画表达重要的时间或状态变化时保留原资源或可访问链接，按阅读器能力配静态预览。下载前检查明显的大资源，必要时给链接替代；校验实际文件类型和引用路径，避免仅信 URL 后缀。尊重原资料的使用权与引用限制。

代码保留版本、依赖、输入与预期输出。实际执行过才标“已运行”；只对照资料检查过则说明核对层级。缺失的实验环境不能伪装成运行通过。

## 引文与事实边界

直接引文逐字对照实际原文，最小化引用长度。空白、换行或 Markdown 格式可用于检索预处理，但负号、小数点、不等号、否定词和关键标点不能为了“匹配通过”而抹掉。

翻译放在引文外并标注，转述不用引号。资料的错误不默默修进引文：指出原文与经核验修正的区别。多来源冲突并列定义、版本、时间或证据，不能混合成一个作者从未提出的结论。

正文保留资料本身的限制与未说明项；读取失败、未下载资源等交付局限也需告知用户，但工具日志不混入知识。
